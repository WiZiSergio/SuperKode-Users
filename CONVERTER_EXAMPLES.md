## 💡 Recomendaciones

- MP3: usa 192 para uso general, 320 para máxima calidad.
- MP4: usa 480 o 720 para un buen equilibrio; 1080 para calidad alta.
- Si el video es largo, prueba calidades medias para reducir tamaño.

## ⚠️ Limitaciones actuales

- Solo YouTube público
- Duración máxima del contenido según configuración del bot
- El conversor requiere FFmpeg instalado

**💡 Tip:** Comienza con las calidades recomendadas (192kbps para MP3, 480p para MP4) y ajusta según tus necesidades específicas.
